This is a self-study project where I learn the basics of React through this tutorial: https://www.youtube.com/watch?v=G6D9cBaLViA&t=495s. 

A summary of the skills learned: JSX, components, conditional rendering, .map(), state, page routing, calling APIs, and useEffect.

Additional features added for extra functionality and to test my new knowledge: a background gradient for more subtle visual interest, and a watchlist for users to come back to movies they want to watch later.
