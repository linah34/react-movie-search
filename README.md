This is a self-study project where I learn the foundations of React through this tutorial: https://www.youtube.com/watch?v=G6D9cBaLViA&t=3494s.

A summary of what I learned: components, conditional rendering, state, page routing, calling APIs, useEffect, and contexts.

I coded additional features and functionality after completing the tutorial to experiment with the tools and knowledge learned, including a gradient background for more visual interest and a watchlist for popular movies the user may want to watch later.
